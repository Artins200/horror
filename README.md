# NOCTURNE — хоррор-плейс для Roblox

**Откройте [`13123.rbxl`](13123.rbxl) или [`Nocturne.rbxl`](Nocturne.rbxl) в Roblox Studio и нажмите Play (F5).** Теперь это **один и тот же исправленный плейс**: старый файл больше не запускает открытую бесконечную лестницу. [`Nocturne.rbxlx`](Nocturne.rbxlx) — текстовая версия этого же плейса. Исходная загрузка `13123.rbxl` при необходимости доступна в истории Git.

Игра вдохновлена форматом прохождения пронумерованных дверей, но использует собственные комнаты, интерьеры, существо и интерфейс — без чужих моделей DOORS и Toolbox-ассетов.

## Что изменилось в здании

- **100 дверей, 18 этажей, 17 лестничных пролётов.** Первая лестница — сразу за дверью 001, затем новая лестничная секция встречается каждые шесть комнат. Выход находится за дверью 100.
- Лестница — не открытая площадка, а **замкнутая часть здания**: сплошные боковые стены, перекрытия, опорный пол, 16 цельных ступеней высотой 0,75 studs, две площадки и непрерывные потолки и поручни. Под верхней площадкой нельзя гулять или провалиться. Дверь наверху совпадает по высоте с входом следующей комнаты.
- Вход и выход есть на обоих концах секции. **Два шкафа расположены на доступных площадках**, а выход из верхнего шкафа возвращает на верхнюю, не под неё. Нет боковых тупиков, в которые можно зайти и застрять.
- Когда старые комнаты удаляются ради производительности, проход назад закрывается стеной. Если из-за сбоя физики персонаж окажется под площадкой или за пределами здания, сервер вернёт его на безопасный пол.

В остальных комнатах процедурно меняются библиотека, галерея, спальня, склад, затопленный коридор и зал. Светильники, древесина, латунные детали, туман, приглушённый свет и звуки создают атмосферу; перед появлением «Шёпота» свет мигает, давая время спрятаться. Есть выносливость, фонарь, смерть с повторной попыткой и финал. Первое лицо использует сглаженные повороты, мягкий наклон, шаги камеры и локальные руки.

### Управление

| Действие | ПК | Телефон | Геймпад |
| --- | --- | --- | --- |
| Идти / смотреть | WASD / мышь | Стик слева / провести справа | Левый / правый стик |
| Открыть дверь, спрятаться | E | Стандартная кнопка взаимодействия | X |
| Выйти из шкафа | E | Кнопка «ВЫЙТИ» | B |
| Бег (с выносливостью) | Shift | Удерживать «БЕГ» | Нажать левый стик |
| Фонарь | F | «СВЕТ» | Y |
| Наклон камеры | Q / R | — | — |

> Выбирайте **Play**, а не **Run**: интерфейс и камера работают в клиентском `LocalScript`, комнаты создаются на сервере. В редакторе уже видны вестибюль и первая закрытая лестница; во время Play они заменяются процедурным зданием. Лучше играть одному или вдвоём: в каждой комнате по два шкафа.

## Исходники и проверки

- [`NocturneLayout.luau`](src/ReplicatedStorage/NocturneLayout.luau) — единые размеры и высоты этажей, ступеней и дверей для сервера и HUD.
- [`NocturneServer.server.luau`](src/ServerScriptService/NocturneServer.server.luau) — генерация здания, серверная проверка дверей, шкафов и опасностей, защита от падения.
- [`NocturneClient.client.luau`](src/StarterPlayer/StarterPlayerScripts/NocturneClient.client.luau) — первое лицо, управление и интерфейс.

После изменений пересоберите оба двоичных файла и XML:

```sh
npm ci                 # Node 20+; зависимости только для сборки и проверок
npm run build          # обновляет 13123.rbxl, Nocturne.rbxl, Nocturne.rbxlx
npm test               # синтаксис, сериализация и проход всех 100 дверей в Lua-макете
```

Для сборки **только** текстового `.rbxlx` достаточно Python 3.9+ и `python3 tools/build_place.py`. Двоичную версию создаёт [`tools/build_binary.mjs`](tools/build_binary.mjs) через `rbx-dom`. Тест [`tools/check_generator.mjs`](tools/check_generator.mjs) исполняет настоящий серверный код в минимальном Lua-макете: открывает 100 дверей, проверяет 17 лестниц, выход из шкафов и возврат с провалившейся площадки. Это **не заменяет проверку в Roblox Studio**: там после Play дополнительно можно выполнить [`tests/StudioSmokeTest.server.luau`](tests/StudioSmokeTest.server.luau) в серверной Command Bar.

В звуковых подсказках используются встроенные `rbxasset://sounds/*`; приватные аудио-ID и внешние плагины не нужны. После проверки опубликуйте плейс через **File → Publish to Roblox**.
