# NOCTURNE v7 — Roblox-хоррор на 100 дверей

**Откройте [`Nocturne-v7.rbxl`](Nocturne-v7.rbxl) в новой вкладке Roblox Studio и нажмите Play (F5), не Run.** `Nocturne.rbxl` и `13123.rbxl` — побайтовые копии v7; `Nocturne.rbxlx` — текстовая версия. Старый `Nocturne-v6.rbxl` оставлен для сравнения, но в нём **нет** изменений v7. Плейс автономен: не нужны Toolbox, плагины или опубликованные Roblox-ассеты.

> В режиме редактирования видны только **статические примеры** первого зала и лестницы. При **Play** сервер удаляет их и строит новый мир. Чтобы проверить случайность, запустите Play дважды: в **Output → Server** выводятся `NOCTURNE v7 run seed` и тип/архитектура первых восьми дверей; они меняются между запусками. В `Workspace/NocturneWorld` есть атрибуты `Seed`, `GenerationBuild = EightRoomPlans-v7`, а у каждой построенной комнаты — `Variant`, `Shape`, `Dark`, `DecorSeed`. Отделка — не единственное отличие: сравните физические колонны, перегородки, боковые проходы, мозаику и своды. При входе сначала построены только комнаты 000–001, следующие секции появляются по мере открытия дверей.

## Что изменено в v7

- **Заметная генерация:** случайным стал даже первый зал. На каждом забеге независимо выбираются интерьеры из 12 типов и **восемь физических архитектурных планов**: открытый зал, аркада, кессонный свод, тамбур, зал с боковыми проходами, ротонда с круглой мозаикой, неф и склеп. Повтор двух последних вариантов исключён, но это не прежний цикл из 12 комнат. Остаются десять настоящих поворотов со смещёнными арками, случайным направлением и семнадцать закрытых лестниц. Внешний каркас 30 × 44 студии и центры дверей не меняются, поэтому этажи стыкуются, выходы из боковых проходов доступны, пол/стены/ступени сталкиваются с персонажем. Маршрут монстров учитывает отверстия во внутренних стенах.
- **Нормальная рука и ключ:** только с найденным ключом видна **одна правая рука собственного обычного аватара R6/R15** (копируются его исходные части/меши, размеры и цвета, а не рисуются кубики). Запястье, локоть и плечо выстраиваются по длинам настоящих частей. Ключ сварен с **реальной** рукой на сервере, виден другим игрокам; владелец видит безопасную для камеры копию **этого же** ключа в ладони. Рука и ключ вместе поднимаются при подборе и поворачиваются при открытии замка. Без ключа руки нет. Движением и коллизиями по-прежнему управляет обычный Roblox Humanoid с нативной камерой `LockFirstPerson`, а не летающая камера.
- **Сумрак вместо слепой черноты:** у комнат с `Dark = true` все основные тёплые светильники погашены, но три слабых **физических** аварийных источника и мягче настроенный общий свет позволяют различать пол/проход **даже при выключенном фонаре**. Это не GUI-осветление и не яркий дневной свет. Во время погони мигают реальные лампы; звуков и текстовых предупреждений при мигании нет.
- **Существа:** Слепой гость переработан по приложенному ориентиру — высокий сутулый худой силуэт, длинные пальцы, тёмные рёбра, бледное овальное лицо и большие чёрные глазницы с костяными ободками, без пальто и светящихся мультяшных зрачков. Погоня получила узкое обугленное тело и холодную маску; Мотылёк — тёмный истощённый торс, пустые глаза и потрёпанные крылья. Это процедурные трёхмерные модели внутри плейса, а не вставленная фотография. Угроза Слепого реагирует на шаги, а не на взгляд; от Погони можно скрыться в шкафу, от Мотылька — выключить фонарь после примерно четырёх секунд визуального предупреждения. Слепой проверяет шкаф и убивает при касании даже присевшего игрока.
- **Скримеры:** после смерти показывается настоящий напавший монстр: силуэт, резкий рывок к лицу, короткие вспышки, затем удержание крупного плана **до** меню повтора. За дверью 100 находится замкнутая финальная комната с фигурой на фоне света; приближение вызывает отдельный скример этой фигуры и только затем экран победы. Нет советов на экране, пасхалок, речевых реплик игроку и звукового эффекта мигания.

По-прежнему доступны физически открывающиеся двери, створки шкафов и три ящика для поиска ключа **в той же комнате, что и запертая дверь**. Подбор ключа не отпирает дверь сам по себе; после смерти или выхода несущий возвращает ключ в открытый ящик для команды. Отступление через одну дверь не останавливает монстров; шкаф не защищает от каждого из них. Из закрытого шкафа остаётся видимый просвет, без текстовых инструкций.

### Управление (не выводится внутри игры)

| Действие | ПК | Телефон | Геймпад |
| --- | --- | --- | --- |
| Движение и обзор | WASD и мышь | Стандартные стики Roblox | Стики |
| Дверь / ящик / ключ / шкаф | E при значке взаимодействия | Стандартный значок касания | X |
| Выйти из шкафа | E | ↩ | B |
| Бег | Shift | » | Нажать левый стик |
| Присесть / встать | C или левый Ctrl | ↓/↑ | B вне шкафа |
| Фонарь | F | ☼ | Y |

## Сборка и проверка

```sh
npm ci
npm run build     # v7, два бинарных алиаса и XML
npm test          # Python + синтаксис Luau + исполняемые офлайн-макеты
```

Исходники: [`NocturneServer.server.luau`](src/ServerScriptService/NocturneServer.server.luau), [`NocturneLayout.luau`](src/ReplicatedStorage/NocturneLayout.luau), [`NocturnePerspective.client.luau`](src/StarterPlayer/StarterPlayerScripts/NocturnePerspective.client.luau), [`NocturneClient.client.luau`](src/StarterPlayer/StarterPlayerScripts/NocturneClient.client.luau). Сборка — `tools/build_place.py` и `tools/build_binary.mjs`. Офлайн-проверки создают/проходят 100 дверей, сравнивают различные seed и **построенные** формы, проверяют доступность ключей, свет в тёмных комнатах, R6/R15 руку/ключ, трёх угроз, финальную модель и очередность скримера/победы.

**Офлайн-проверки не заменяют Play-тест в Roblox Studio: здесь Roblox Studio недоступна, визуальный результат в движке не подтверждён.** В Studio запустите именно v7 в новой вкладке и посмотрите первые комнаты в двух отдельных Play, затем проверьте выключенный фонарь в комнате с `Dark = true`, ключ перед дверью 005, три встречи (Погоня около 006, Слепой около 010, Мотылёк около 016) и финал после 100-й. Для проверки аватара выполните [`tests/StudioAvatarCheck.client.luau`](tests/StudioAvatarCheck.client.luau) в **Client Command Bar** до/после взятия ключа. Для стартовой геометрии и seed — [`tests/StudioSmokeTest.server.luau`](tests/StudioSmokeTest.server.luau) в **Server Command Bar** сразу после старта. Если в Play что-то выглядит иначе, чем описано, пришлите скриншот и первые красные ошибки из **Output → Client/Server**.
